# RunnerLoom

Ephemeral GitHub Actions runners on your own machines.

RunnerLoom is being built from the v0.1 design baseline: a Go CLI, one controller,
LAN-connected nodes, resource-aware scheduling, hard reservations and disposable
KVM/libvirt virtual machines. The source implementation and its verification
status are tracked in this repository.

**Development status:** implementation in progress. Not production-ready. No host
network settings or existing virtual machines are modified by this bootstrap.

The repository visibility and project licensing have not been changed.
